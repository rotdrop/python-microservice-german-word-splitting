# German Word Splitter Gentoo Overlay

This overlay provides the `app-misc/german-word-splitter` package, a FastAPI
service for splitting German compound words.

## Install

Add the published overlay and install the package:

```sh
sudo eselect repository add german-word-splitter git https://github.com/rotdrop/german-word-splitter-gentoo-overlay
sudo emerge --sync german-word-splitter
sudo emerge --ask app-misc/german-word-splitter
```

The package installs the service under `/opt/german-word-splitter`, along with
a dedicated `german-word-splitter` user and group. By default it uses the
OpenRC init script. To install the systemd unit, enable the `systemd` USE flag
in `/etc/portage/package.use`:

```text
app-misc/german-word-splitter systemd
```

The service reads its settings from `/etc/default/german-word-splitter`.
After installation, start it with OpenRC:

```sh
sudo rc-update add german-word-splitter default
sudo rc-service german-word-splitter start
```

Or, when built with the `systemd` USE flag:

```sh
sudo systemctl enable --now german-word-splitter
```

## Packages and maintenance

The overlay contains the live `app-misc/german-word-splitter-9999` ebuild and
the required `acct-user` and `acct-group` packages. Published release ebuilds
are generated by the repository's GitHub Actions workflow for recent releases.
The published overlay is generated from
[`contrib/gentoo`](https://github.com/rotdrop/python-microservice-german-word-splitting/tree/main/contrib/gentoo);
send overlay changes to that source repository rather than editing the
generated overlay directly.

The live ebuild needs network access while building to fetch Python
dependencies and the German dictionary.
